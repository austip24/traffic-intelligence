| Dataset                        | What you get                                          | Use in app           |
| ------------------------------ | ----------------------------------------------------- | -------------------- |
| **OpenStreetMap**              | Roads, intersections, lanes, speed limits, road types | Base road network    |
| **FHWA HPMS**                  | AADT, road characteristics, functional class          | Traffic volume       |
| **FHWA traffic counts / TMAS** | Continuous traffic counts and historical trends       | Time-series traffic  |
| **NHTSA FARS**                 | Fatal crashes + locations + circumstances             | Safety analysis      |
| **State DOT crash data**       | Often much more detailed crash records                | Local crash analysis |
| **GTFS**                       | Bus/train routes, stops, schedules                    | Public transit       |
| **Census ACS**                 | Population, income, commuting, vehicle ownership      | Demand/context       |
| **TIGER/Line**                 | Census boundaries + geographic features               | Spatial aggregation  |
| **EPA Air Quality**            | Pollution measurements                                | Environmental impact |
| **OSM bike/pedestrian data**   | Bike lanes, sidewalks, paths                          | Multimodal analysis  |
